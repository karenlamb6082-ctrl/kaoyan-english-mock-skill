# 考研英语一循环命题 SKILL · 1.1

面向个人学习的跨AI平台命题规则：来源核查、整卷设计、选项分析、盲审、排版和跨卷轮换。

**仅限个人、非商业学习使用。商用、面向他人的服务和再分发需另行授权。** 这是源代码可见的限制用途项目，不是MIT开源项目。详见 [许可](LICENSE.md)。

## 开始使用

**想直接拿到可打印试卷，必须在能实际生成并提供可下载 PDF 文件的AI环境中使用。** 只会聊天、能读附件或能写代码，并不代表能交付PDF；SKILL本身不会给模型增加文件生成工具。

开始出整卷前，先让AI生成一页包含中文、英文和简单图形的测试PDF，提供真实下载附件，并确认自己能打开。再分别确认能否生成作文图、将PDF逐页转成图片并查看。小样成功只是能力预检，不代替整卷排版验收。

只有文字输出的环境可以辅助写题，但不能直接交付PDF；只能输出HTML的环境还需要用户另行导出，不能宣传为“一句话直接获得PDF”。详见 [能力要求](PLATFORM_GUIDE.md)。

- 普通聊天AI：上传 [单文件提示](UNIVERSAL_PROMPT.md)，按 [使用说明](START_HERE.md) 开始。
- 支持Skills的工具：下载完整仓库并加载 [SKILL.md](SKILL.md)。
- 本地工具：Python 3.10+，执行 `python scripts/preflight.py`。

每位使用者从空白系列开始；公开包不包含原作者历次试卷、答案、作答数据和私人系列状态。

## 1.1的变化与边界

审核阶段不可跳级；看过答案的自检不算盲审；来源按主张映射；记录最强干扰项及其错误边界；修改后重新审核；字号、边距及全页检查更加明确。

结构检查通过不等于题目质量或难度通过。未经考生数据不能声称真题等值；不同AI平台的实际能力须自行核验。
